Detailed Description

UART interface implementation for nRF52840 using Zephyr.

This module provides UART initialization, asynchronous TX/RX handling, and APIs to send and receive data using Zephyr RTOS features.

◆ uart_init()

int uart_init ( void )

Initialize and configure UART peripheral.

Initialise the UART peripheral and associated kernel objects.

Steps:

  1. Verify device readiness
  2. Apply runtime configuration
  3. Register interrupt-driven callback
  4. Enable RX with timeout
  5. Send welcome message
  6. Initialize RX semaphore
Returns
0 on success or FATAL_ERR on failure
