Detailed Description

UART driver interface for the temperature‑controller project running on the nRF52840‑DK under Zephyr RTOS.

The module wraps Zephyr’s asynchronous UART API to offer:

  • Non‑blocking transmission with a simple uart_send helper.
  • Interrupt‑driven reception that collects characters in an internal buffer and dispatches complete frames through a Zephyr message queue (uart_msgq).
  • Basic runtime initialisation (uart_init) and buffer‑management helpers.

All definitions are implemented in uart.c.

◆ uart_init()

int uart_init ( void )

Initialise the UART peripheral and associated kernel objects.

This function configures the UART device defined by UART_NODE for asynchronous operation, allocates the RX buffer, and registers uart_cb as the event callback.

Return values
0Success.
-errnoNegative error code propagated from Zephyr drivers.

Initialise the UART peripheral and associated kernel objects.

Steps:

  1. Verify device readiness
  2. Apply runtime configuration
  3. Register interrupt-driven callback
  4. Enable RX with timeout
  5. Send welcome message
  6. Initialize RX semaphore
Returns
0 on success or FATAL_ERR on failure

◆ uart_msgq

struct k_msgq uart_msgq
extern

Message queue receiving complete UART frames.

Each queue element is a null‑terminated string whose maximum length is RXBUF_SIZE bytes. Application threads can block on this queue using k_msgq_get() to wait for new frames.
