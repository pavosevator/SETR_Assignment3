Detailed Description

Command processor for UART-based control of the sensor node. Parses received frames, validates checksum, and executes commands:

  • 'M': set max temperature threshold
  • 'C': request current temperature
  • 'S': set duty cycle Uses SOF ('#') and EOF ('!') delimiters and a 3-digit checksum.

Authors: Ivan PAVOSEVIC, Enzo DOS SANTOS

◆ cmdProcessor()

int cmdProcessor ( void )

Processes the chars in the RX buffer looking for commands.abort.

Main command processor routine.

  • Scans RX buffer for a complete frame (#...!)
  • Validates checksum
  • Executes command based on command ID
  • Builds and queues response frame in TX buffer
  • Cleans up processed bytes from RX buffer
    Returns
    CMD_OK or error code
