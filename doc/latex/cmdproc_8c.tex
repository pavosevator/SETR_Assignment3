\doxysubsection{Detailed Description}
Command processor for UART-\/based control of the sensor node. Parses received frames, validates checksum, and executes commands\+: 


\begin{DoxyItemize}
\item \textquotesingle{}M\textquotesingle{}\+: set max temperature threshold
\item \textquotesingle{}C\textquotesingle{}\+: request current temperature
\item \textquotesingle{}S\textquotesingle{}\+: set duty cycle Uses SOF (\textquotesingle{}\#\textquotesingle{}) and EOF (\textquotesingle{}!\textquotesingle{}) delimiters and a 3-\/digit checksum.
\end{DoxyItemize}

Authors\+: Ivan PAVOSEVIC, Enzo DOS SANTOS
