\doxysubsection{Detailed Description}
GPIO interface for button and LED handling using Zephyr RTOS. 

This header defines initialization and control functions for buttons and LEDs. It uses GPIOs defined in the device tree via DT aliases ({\ttfamily sw0} to {\ttfamily sw3}, {\ttfamily led0} to {\ttfamily led3}).
