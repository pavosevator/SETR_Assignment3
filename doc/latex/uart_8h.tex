\doxysubsection{Detailed Description}
UART driver interface for the temperature‑controller project running on the n\+RF52840‑\+DK under Zephyr RTOS. 

The module wraps Zephyr’s asynchronous UART API to offer\+:
\begin{DoxyItemize}
\item Non‑blocking transmission with a simple \doxylink{uart_8c_a022f9387e4c678486f22ac4f0c677438}{uart\+\_\+send} helper.
\item Interrupt‑driven reception that collects characters in an internal buffer and dispatches complete frames through a Zephyr message queue (\doxylink{uart_8h_a5ef38de1537b76a8b3c6ce5a89413b72}{uart\+\_\+msgq}).
\item Basic runtime initialisation (\doxylink{uart_8c_af619fe0b949297d40d50ab9f41e96999}{uart\+\_\+init}) and buffer‑management helpers.
\end{DoxyItemize}

All definitions are implemented in {\ttfamily \doxylink{uart_8c}{uart.\+c}}.
