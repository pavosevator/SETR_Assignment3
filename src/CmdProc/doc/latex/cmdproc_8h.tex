\doxysubsection{Detailed Description}
Header file for command processor module for a thermal process control system. 

This module processes commands received via UART for a thermal process control system. It is designed to handle various commands related to temperature regulation, including setting and reading temperature values, configuring controller parameters, and managing system status. The module ensures robust communication by validating command frames and checksums, and it maintains a history of temperature readings for monitoring and diagnostic purposes.

\hypertarget{cmdproc_8h_Overview}{}\doxysubsection{\texorpdfstring{Overview}{Overview}}\label{cmdproc_8h_Overview}
The command processor module is responsible for interpreting UART commands and executing corresponding actions on the thermal control system. It supports a range of commands for real-\/time temperature monitoring and system configuration. The module uses a circular buffer to maintain a history of temperature readings, which can be useful for diagnostics and logging.\hypertarget{cmdproc_8h_Commands}{}\doxysubsection{\texorpdfstring{Commands}{Commands}}\label{cmdproc_8h_Commands}
The module supports the following commands\+:
\begin{DoxyItemize}
\item \textquotesingle{}C\textquotesingle{}\+: Reads the current temperature value from the sensor. Format\+: \#\+Cyyy! where yyy is the checksum.
\item \textquotesingle{}M\textquotesingle{}\+: Sets the maximum allowed temperature. Format\+: \#\+Mxxxyyy! where xxx is the temperature and yyy is the checksum.
\item \textquotesingle{}S\textquotesingle{}\+: Sets the controller parameters. Format\+: \#\+Sxxx...xxxyyy! where xxx...xxx are the parameters and yyy is the checksum.
\end{DoxyItemize}\hypertarget{cmdproc_8h_Data}{}\doxysubsection{\texorpdfstring{Structures}{Structures}}\label{cmdproc_8h_Data}
The module uses the following key data structures\+:
\begin{DoxyItemize}
\item UARTRx\+Buffer\+: A buffer to store incoming UART data.
\item UARTTx\+Buffer\+: A buffer to store outgoing UART data.
\item t\+History\+: A circular buffer to store the history of temperature readings.
\end{DoxyItemize}\hypertarget{cmdproc_8h_Functions}{}\doxysubsection{\texorpdfstring{Functions}{Functions}}\label{cmdproc_8h_Functions}
The module includes the following key functions\+:
\begin{DoxyItemize}
\item \doxylink{cmdproc_8h_afbdfe0465dfd34a5f244fe41fa27c12a}{cmd\+Processor()}\+: Processes the incoming commands and executes corresponding actions.
\item \doxylink{cmdproc_8h_af4b643cbe4d6c4473eec58b015044cdd}{check\+Sof\+Eof()}\+: Checks for the presence of start-\/of-\/frame (SOF) and end-\/of-\/frame (EOF) markers.
\item \doxylink{cmdproc_8h_adea97048aa6fcc4293f9de8509ad637f}{calc\+Checksum()}\+: Calculates the checksum for a given data buffer.
\item \doxylink{cmdproc_8h_a5e99bf56b7fa2aa95aa8c3752af46b34}{check\+Rx\+Checksum()}\+: Verifies the checksum of received commands.
\item \doxylink{cmdproc_8h_a67ae8a79a708a3c5471668bddbd16400}{rx\+Char()} and \doxylink{cmdproc_8h_abdb4363f0662688850bbcdfb59ce4566}{tx\+Char()}\+: Functions to receive and transmit characters via UART.
\item \doxylink{cmdproc_8h_a5c2454bba0f5fd587bf2c6277df9ee7e}{add\+In\+History()}\+: Adds a temperature reading to the history buffer.
\item \doxylink{cmdproc_8h_ae220cfb8f7e5a90196ef7273d0ada926}{generate\+Char\+Array()}\+: Converts numerical values to character arrays for transmission.
\end{DoxyItemize}\hypertarget{cmdproc_8h_Usage}{}\doxysubsection{\texorpdfstring{Usage}{Usage}}\label{cmdproc_8h_Usage}
To use this module, initialize the UART interface and call the \doxylink{cmdproc_8h_afbdfe0465dfd34a5f244fe41fa27c12a}{cmd\+Processor()} function periodically to process incoming commands. Ensure that the UART buffers are properly managed to avoid overflows and data corruption.
